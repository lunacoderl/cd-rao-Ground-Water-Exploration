## 📌 Overview

Official web application for **C.D.Rao Ground Water Exploration Consultancy**, led by experienced geologist **Chigurupati Durga Rao (M.Sc Geology)**. 

The consultancy specializes in scientific groundwater surveys, pinpoint borewell point identification, vertical electrical sounding (VES geophysical surveys), multi-frequency 3D earth scanning, and yield estimation for agricultural lands, residential apartments, commercial projects, and industrial layouts.

## 🚀 Key Features

- **Pixel-Accurate Light Themed UI**: Clean, modern aesthetic with high contrast, crisp typography, and responsive layouts across all device sizes.
- **2-Page Primary Architecture**:
  - **Homepage (`/`)**: Rich single-page journey featuring Hero, Trust Strip, About the Geologist, Testimonials, Real Site Works, 8 Core Services, 3D Earth Scanning strata stack, 5-step Survey Workflow, Video Showcase, Filterable Gallery, Client Reviews, FAQ, and Direct Contact Booking Card.
  - **Reusable Service Details Page (`/services/:serviceSlug`)**: Detailed technical pages for all 8 exploration services with depth metrics, execution roadmap, equipment specs, and benefits.
- **Uncropped Authentic Field Assets**:
  - 14 real site videos with interactive video modal player.
  - High-resolution field photos displayed in full natural aspect ratios (`object-contain`) without cropping.
- **Interactive Booking & Enquiry System**:
  - Global survey booking modal with automated service pre-selection when clicking *"Book This Service"*.
  - Direct WhatsApp & phone click-to-call integration (`+91 9949401970`).
- **Comprehensive SEO Optimization**:
  - Complete `sitemap.xml` with Google image metadata.
  - `robots.txt` configured with crawler guidelines.
  - `LocalBusiness` / `ProfessionalService` JSON-LD schema markup with geo-coordinates for Visakhapatnam.
  - Canonical tags, Open Graph meta tags, and Twitter Cards.
- **Vercel Ready**:
  - Includes `vercel.json` with SPA route rewrites, clean URLs, security headers, and asset caching rules.

## 💻 Local Setup & Development

### 1. Clone the repository
```bash
git clone https://github.com/lunacoderl/cd-rao-Ground-Water-Exploration.git
cd cd-rao-Ground-Water-Exploration
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
The compiled output will be generated in the `dist/` directory.

---

## 🌐 Deploy to Vercel

This repository includes a preconfigured `vercel.json`:
1. Push this repository to GitHub.
2. Import the repository in [Vercel](https://vercel.com/new).
3. Framework Preset: **Vite** (automatically detected).
4. Click **Deploy**.
